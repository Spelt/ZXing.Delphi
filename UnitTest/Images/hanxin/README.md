# Han Xin Code samples

- `zint-vectors.txt`: the symbols of the encode tests of zint
  (backend/tests/test_hanxin.c, test_encode; BSD-3-Clause, Copyright (C)
  2019-2026 Robin Stuart), the ones in UNICODE_MODE. Per line, tab separated:
  the ECI (-1: none), the text as UTF-8 bytes (hex), the size, then the rows
  (hex, 4 modules per digit, the first the highest bit, padded with 0).
- The examples of Wikimedia Commons by Alexandr.gavriluk (CC0 1.0, public
  domain), made with Aspose.BarCode:
  - `hanxin-v01-wikimedia.png`: "File:Han Xin Code Example V01.png". Text:
    `Aspose.BarCode`.
  - `hanxin-v04-wikimedia.png`: "File:Han Xin Code Example V04.png". Text:
    `Aspose.BarCode for 1D & 2D barcodes`.
  - `hanxin-v22-wikimedia.png`: "File:Han Xin Code Example V22.png". Text:
    `Aspose.BarCode is a powerful development library to generate & recognize
    1D & 2D barcodes. Developers can easily add barcode generation and
    scanning functionality to their applications.`
  - `hanxin-v22-wikimedia-tilted.jpg`: the same, turned -25 degrees, scaled
    0.7, in perspective (tilt 0.12 and 0.08), JPEG quality 80.
  - `hanxin-v84-wikimedia.png`: "File:Han Xin Code Example V84.png" (version
    84, 189 x 189 modules): about 1600 characters about Aspose.BarCode for
    .NET.
