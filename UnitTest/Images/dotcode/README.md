# DotCode samples

The examples of Wikimedia Commons by Alexandr.gavriluk (CC0 1.0, public
domain), made with Aspose.BarCode; the PNG renders (500 pixels wide) of the SVG
files.

- `dotcode-23x22-wikimedia.png`: "File:DotCode Example 23W22H.svg". Text:
  `Aspose.Barcode`.
- `dotcode-23x22-wikimedia-tilted.jpg`: the same, turned 20 degrees, scaled
  0.8, in perspective (tilt 0.15 and 0.1), JPEG quality 80.
- `dotcode-27x10-wikimedia.png`: "File:DotCode Example 27W10H.svg". Text:
  `Aspose`.
- `dotcode-57x60-wikimedia.png`: "File:DotCode Example 57W60H.svg" (the dots up
  to the edge of the image; the Reed-Solomon check codewords in one block,
  not interleaved). Text: `Aspose.BarCode for .NET is a powerful development
  library to generate & recognize 1D & 2D barcodes from any image types`.
